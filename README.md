# Coldplay Landing Page

Landing page sobre a banda **Coldplay**, desenvolvida como atividade de faculdade em 2024.

O desafio era criar uma página para uma banda usando apenas **HTML e CSS**. Todo o código foi escrito à mão, sem frameworks, bibliotecas ou ferramentas de IA.

## Seções da página

- **Biografia**: a história da banda, da formação em Londres até os dias de hoje
- **Membros**: Chris Martin, Guy Berryman, Jonny Buckland, Will Champion e Phil Harvey
- **Discografia**: 9 álbuns de estúdio, de *Parachutes* (2000) a *Music of the Spheres* (2021), com a lista de faixas de cada um
- **Galeria**: fotos da banda em um bloco expansível (`<details>`)
- **Shows**: datas da *Music of the Spheres World Tour* em 2024
- **Vídeo**, **compra de ingressos**, **formulário de contato** e **redes sociais**

## Tecnologias

- HTML5
- CSS3: Flexbox, Grid, `@keyframes` (título com cores animadas) e media queries para telas menores

## Como executar

Não precisa instalar nada:

```bash
git clone https://github.com/Irlamfernandes/coldplay-landing-page.git
cd coldplay-landing-page
```

Depois, abra o arquivo `index.html` no navegador.

## Estrutura

```
├── index.html   # estrutura e conteúdo da página
├── style.css    # estilos e responsividade
└── imagens/     # fotos, capas de álbuns e vídeo
```

## Observações

- Projeto acadêmico, sem fins comerciais. As imagens, o vídeo e o nome Coldplay pertencem aos seus respectivos donos.
- O formulário de contato é apenas visual e não envia mensagens.
